## Architecture Decision

The current deployment is autoscaled, so an in-process timer is not reliable and will not be added. The portable design is a Job Sarthi internal scheduler endpoint protected by an application-owned server secret, invoked on a defined schedule by an external cron configuration. A repository workflow may provide a ready-to-enable scheduler implementation, but it will only run after the deployment URL and `JOB_SCHEDULER_SECRET` are configured securely outside source control.

> The migration removes Manus from normal-user and scheduler authentication paths. It does not claim that email delivery is configured: the in-app digest remains the real fallback until an email provider is configured.
